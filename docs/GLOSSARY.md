## 中心となる 3 つ

### ROI — Region of Interest（関心領域）

画像のうち**注目したい部分**を指す一般的な用語。医用画像では「この範囲を測る」
「この範囲だけを切り出す」という意味で使う。

本システムでは**胸部野**（肺野＋縦隔＋横隔膜）を指す。1 枚の胸部X線から

- 肺野の mask（どこが肺か）
- 胸部野の mask・bbox・crop（肺・心臓・その間・横隔膜まで）

を作る処理を「ROI 抽出」と呼ぶ。検索は胸部野どうしを比べる。肺野を部位に分けないのは、
部位単位の正解データが無いためである。

→ [MULTIMODAL.md §5](MULTIMODAL.md) / 処理の流れは [DESIGN.md §3.1](DESIGN.md)

### 胸部野の分類器（所見の推定）

胸部野の画像特徴から、14 所見それぞれの確率を出す学習済みの線形分類器。データセットの
ラベルは画像単位なので、単位が画像 1 枚であればそのまま教師データになる。
確率は検索の 2 段目（並べ替え）と、画面の「所見の推定（研究用・診断ではありません）」に
使う。**データセットのラベルとは別物で、診断でもない。**

→ [MULTIMODAL.md §6](MULTIMODAL.md)

### MIL — Multiple Instance Learning（多重インスタンス学習）

**「袋」にだけラベルがあり、中の「粒」のどれが該当するかは判らない**問題を扱う枠組み。
本システムは画像 1 枚を単位とし、画像単位のラベルで直接学習するので、検索の経路では使わない。

### U-Net

**略語ではない。** ネットワークの形が U 字（縮めてから広げ、同じ高さどうしを
横に繋ぐ）であることに由来する名前である。Ronneberger ら（2015）が生物医学画像の
**セグメンテーション**（画素ごとの分類）のために提案した。

本システムでは**肺野の切り出し**に使う。輝度の閾値による規則ベースは corpus の
約 4 分の 1 で破綻し、心臓の mask も出せないため、U-Net を必須にしている。

→ [MULTIMODAL.md §7](MULTIMODAL.md)

## 画像処理

| 用語 | 意味 |
|---|---|
| **mask** | 「ここが対象」を画素ごとに示す白黒の画像 |
| **bbox** | bounding box。対象を囲む最小の長方形 |
| **crop** | 画像から切り出した一部。検索で比べる単位 |
| **セグメンテーション** | 画素ごとに「何であるか」を分類すること |
| **正規化（normalize）** | 明るさの範囲を揃え、向きと大きさを揃える前処理 |
| **Dice / IoU** | 2 つの mask がどれだけ重なるかの指標。1.0 が完全一致 |

→ 前処理は [MULTIMODAL.md §3.1](MULTIMODAL.md)、評価は [§8](MULTIMODAL.md)

## 検索とベクトル

| 用語 | 意味 |
|---|---|
| **埋め込み（embedding）** | 画像や文を数値の並び（ベクトル）に変えたもの |
| **次元** | ベクトルの長さ。512 次元なら数値が 512 個 |
| **cosine 距離** | ベクトルの向きの近さ。値が小さいほど似ている |
| **近似最近傍（ANN）** | 全部を調べずに「だいたい近いもの」を高速に探す方法 |
| **HNSW** | ANN の索引の一種。文章を含む検索の 1 段目（BiomedCLIP）で使う |
| **多段検索（2 段検索）** | 1 段目で候補を絞り、2 段目で厳密に並べ直す方式。文章を含む検索で使う |
| **全件検索（profile）** | 索引を使わず全行と厳密に比べる方式。画像だけの検索の既定（15 次元の所見プロファイル） |
| **再ランキング（rerank）** | 2 段目で順位を付け直すこと |
| **backfill** | 既にある行へ、後から値を埋める作業 |

→ [MULTIMODAL.md §4](MULTIMODAL.md)

## モデル

| 用語 | 意味 |
|---|---|
| **BiomedCLIP** | 画像と文を同じ空間に写すモデル。1 段目で使う |
| **RAD-DINO** | 胸部X線に特化した画像モデル。胸部野の分類器の入力を作る |
| **backbone** | 特徴を取り出す土台のモデル。本システムでは凍結して使う |
| **凍結（freeze）** | 学習で重みを更新しないこと |
| **ONNX** | 学習の枠組みに依らないモデルの保存形式。推論だけなら軽い |
| **mask pooling** | patch token を mask の被覆率で加重平均し、枠の中の特徴を 1 本にすること |

→ [MULTIMODAL.md §1](MULTIMODAL.md) / [§6.2](MULTIMODAL.md)

## データと評価

| 用語 | 意味 |
|---|---|
| **ChestX-ray14** | NIH が公開する胸部X線データセット（112,120 枚） |
| **CheXmask** | ChestX-ray8 等に肺野の mask を付けた公開データ |
| **gold box** | 正解として人が付けた病変の枠（880 枚）。枠の妥当性（胸部野に入るか）を測るのに使う |
| **帰無（null）** | 「何も効いていないとき」の成績。比較の基準 |
| **AUC** | 分離できているかの指標。0.5 が当てずっぽう |
| **lift** | 帰無に対して何倍良いか |

→ [MULTIMODAL.md §3.2](MULTIMODAL.md)

> **帰無を必ず測る。** 画像の統計量だけ（医学的意味なし）でも AUC 0.696 に届く。測らずに
> 「効いた」と言うと、撮影条件の相関を所見の検出と取り違える。

## 版に関する用語

再現性のために、何が変わったらどの版を上げるかを決めてある。

| 版 | 何が変わると上げるか |
|---|---|
| `roi_model_version` | ROI の profile（`algorithm_version` + パラメータの SHA） |
| `preprocess_version` | crop の作り方 |
| `embedding_model_version` | モデルとその revision |

**版が違うベクトルは混ざらない。** 主キーに含めてあるためである。

→ [DESIGN.md §4.6](DESIGN.md)
